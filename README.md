# ProjectHub - Project Management Tool

A Full Stack Project Management Tool (similar to Trello) built as part of the **CodeAlpha Full Stack Development Internship**. 

## 🔗 Live Links
- **Live Frontend (Vercel):** [https://codealphaprojectmanagement-frontend.vercel.app/](https://codealphaprojectmanagement-frontend.vercel.app/)
- **Live Backend API (Render):** [https://codealpha-projectmanagement-k7ii.onrender.com](https://codealpha-projectmanagement-k7ii.onrender.com)

## 🚀 Features
- **User Authentication:** Secure Registration & Login using JWT.
- **Project Management:** Create and view multiple projects.
- **Task Board:** Add tasks to specific projects.
- **Status Tracking:** Move tasks between "To Do" and "Done" columns.

## 💻 Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Mongoose)
- **Authentication:** JWT (JSON Web Tokens)
